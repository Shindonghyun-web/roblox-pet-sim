# 프롬프트 모음 — 복사해서 쓰는 AI 요청문

AI에게 일을 시킬 때 그대로 복사해서 쓰는 문장 모음이에요.
`[빈칸]` 부분만 내 상황에 맞게 바꿔서 붙여넣으면 됩니다.

> 규칙(폴더 구조, 이름, 안전 규칙)은 `CLAUDE.md`에 이미 있어서 AI가 알아서 지켜요.
> 그래서 여기 프롬프트에는 **"이번에 무엇을 할지"**만 적어요.

| 파일 | 언제 쓰나요? |
|---|---|
| [01_세션시작.md](01_세션시작.md) | 새 대화를 시작할 때 (맨 처음 한 번) |
| [02_새기능.md](02_새기능.md) | 새 기능을 추가하거나 빌드 순서 다음 단계로 갈 때 |
| [03_오류수정.md](03_오류수정.md) | Play를 눌렀더니 빨간 오류가 날 때, 또는 뭔가 이상하게 동작할 때 |
| [04_값조정.md](04_값조정.md) | 가격, 확률, 속도 같은 숫자만 바꾸고 싶을 때 |

## 쓰는 순서

1. 새 대화를 열면 **세션시작** 프롬프트부터 붙여넣어요.
2. AI가 요약을 보여주면, 하고 싶은 일에 맞는 프롬프트를 골라 붙여넣어요.
3. 코드를 받으면 AI가 알려준 **✅ 확인 방법**대로 Studio에서 Play로 테스트해요.
