# 숫자(밸런스)만 바꾸기

가격, 확률, 속도, 쿨타임 같은 숫자는 모두 `Config` 한 곳에 모여 있어요.
그래서 숫자만 바꿀 때는 **Config만** 고치면 돼요.

## 기본

```
[빈칸: 바꿀 값, 예) 알 가격]을 [빈칸: 지금 값]에서 [빈칸: 새 값]으로 바꿔줘.
Config만 고쳐줘.
```

## 여러 개를 한 번에

```
아래 값들을 바꿔줘. Config만 고쳐줘.
- [빈칸: 값 이름]: [빈칸: 지금 값] → [빈칸: 새 값]
- [빈칸: 값 이름]: [빈칸: 지금 값] → [빈칸: 새 값]
Config만으로 안 되는 게 있으면 고치기 전에 이유를 먼저 말해줘.
```

## 어떤 값이 있는지 모를 때

```
Config에 있는 값들을 표로 보여줘. 이름, 지금 값, 무슨 뜻인지(단위 포함) 세 칸으로.
코드는 고치지 마.
```

> 가격이나 확률처럼 중요한 값을 바꿨다면, AI에게 "02_PRD.md에서 고칠 부분도 알려줘"라고 덧붙이세요.
