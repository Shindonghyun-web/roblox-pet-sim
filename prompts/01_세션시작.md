# 세션 시작 — 새 대화를 열 때 맨 처음 붙여넣기

AI는 대화가 바뀌면 이전 내용을 기억하지 못해요.
그래서 새 대화마다 규칙서와 설계도를 먼저 읽게 해요.

## 기본

```
CLAUDE.md, 02_PRD.md, 03_진행기록.md를 먼저 끝까지 읽어줘.
그다음 아래 세 가지를 짧게 요약해줘.
1. 이 게임이 어떤 게임인지 (한두 줄)
2. 빌드 순서에서 끝난 단계와 다음에 할 단계, 진행기록에 적힌 알려진 버그
3. PRD에 [작성 필요]로 비어 있는 칸 중 다음 단계에 필요한 것
요약만 하고, 코드는 내가 부탁하기 전까지 만들지 마.
```

## 이어서 작업할 때 (지난번에 하던 게 있을 때)

```
CLAUDE.md, 02_PRD.md, 03_진행기록.md를 먼저 읽어줘.
지난번에는 [빈칸: 예) 빌드 순서 3단계 코인 줍기]까지 했어. (진행기록에 적어 뒀다면 이 줄은 지워도 돼)
지금 상태를 요약하고, 다음에 할 일을 제안해줘. 코드는 아직 만들지 마.
```
