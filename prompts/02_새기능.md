# 새 기능 추가

## 빌드 순서의 다음 단계 만들기

```
PRD의 빌드 순서 [빈칸: 단계 번호]단계([빈칸: 단계 이름])만 구현해줘.
- 시작 전에 새로 만들 파일과 고칠 파일 목록을 먼저 보여줘.
- 내가 OK하면 그때 코드를 줘.
- 다른 단계 기능은 미리 만들지 마.
- PRD에 [작성 필요]로 남은 칸이 필요하면 추측하지 말고 먼저 물어봐.
```

## PRD에 없는 작은 기능 추가하기

```
[빈칸: 예) 코인을 주우면 효과음이 나게] 해줘.
- 이 기능이 PRD의 어디에 해당하는지, 아니면 새로 추가되는 건지 먼저 말해줘.
- 고칠 파일과 새로 만들 파일 목록을 먼저 보여주고, 내가 OK하면 코드를 줘.
- 끝나면 02_PRD.md에 추가해야 할 내용을 문장으로 알려줘.
```

## 한 파일만 손보기

```
[빈칸: 파일 이름, 예) HUDController]만 고쳐서 [빈칸: 바꾸고 싶은 점]을 해줘.
다른 파일은 그대로 둬.
```

## 작업이 끝난 뒤

```
방금 바꾼 내용 때문에 02_PRD.md에서 고쳐야 할 부분이 있으면 알려줘.
빌드 순서 단계가 끝났으면 체크 표시도 제안해줘.
03_진행기록.md에 적을 내용도 정리해줘.
```
