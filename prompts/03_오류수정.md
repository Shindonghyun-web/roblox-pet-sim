# 오류 고치기

> 오류가 나면 Output 창(보기 → 출력)의 **빨간 글자를 그대로 복사**해서 붙여넣으세요.
> "안 돼요"보다 훨씬 빨리 고쳐져요.

## 빨간 오류가 날 때

```
Play를 누르고 [빈칸: 내가 한 행동, 예) 상점 버튼을 눌렀더니] Output에 이 오류가 나와:

[빈칸: 빨간 오류 메시지 전체 붙여넣기]

원인을 먼저 설명해줘. 어느 파일 몇 번째 줄에서 왜 났는지 알려주고, 추측이면 추측이라고 말해줘.
그다음 관련된 파일만 고쳐줘. 다른 파일은 건드리지 마.
```

## 오류는 없는데 이상하게 동작할 때

```
[빈칸: 내가 한 행동]을 하면 [빈칸: 원래 되어야 하는 것]이 되어야 하는데,
실제로는 [빈칸: 실제로 일어난 일]이 돼. Output에 빨간 오류는 없어.
어느 파일이 원인일지 먼저 짐작해서 알려주고, 확인하려면 내가 무엇을 보면 되는지 알려줘.
고치기 전에 고칠 파일을 먼저 말해줘.
```

## 저장이 안 될 때

```
Stop했다가 다시 Play하면 [빈칸: 예) 코인이 0으로 돌아가].
Output에 나온 [DataService] 로그는 이거야:

[빈칸: DataService 관련 로그 붙여넣기, 없으면 "없음"]

원인을 먼저 설명하고, DataService만 고쳐줘.
```
