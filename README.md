# Roblox 바이브코딩 템플릿

AI(Claude Code 등)와 함께 로블록스 게임을 만들기 위한 **시작 틀**이에요.
장르와 상관없이 쓸 수 있고, 코딩을 처음 하는 사람도 따라 할 수 있게 만들었어요.

## 파일 안내 (번호 순서대로 보면 돼요)

| 파일 | 하는 일 |
|---|---|
| `CLAUDE.md` | AI가 매번 읽는 **규칙서** (어떻게 만드는지) |
| `01_사용가이드.md` | 이 틀을 쓰는 방법, AI에게 말하는 법, Rojo 설치 |
| `02_PRD.md` | 게임 **설계도** (무엇을 만드는지, 빌드 순서) |
| `03_진행기록.md` | 어디까지 했는지, 다음 할 일, 알려진 버그 |
| `04_테스트체크리스트.md` | 기능을 만들 때마다 Studio에서 확인할 항목 |
| `prompts/` | 복사해서 쓰는 AI 요청문 모음 |
| `default.project.json` | Rojo 설정 (어느 폴더를 Studio 어디에 넣을지) |
| `src/` | 게임 코드 (Rojo가 Studio로 넣어 줌) |

## 새 게임 시작하는 순서

1. GitHub에서 이 저장소를 복사해 새 저장소를 만들어요. (이 저장소를 템플릿으로 쓰거나, 폴더째 복사)
2. `02_PRD.md`의 `[작성 필요]` 칸을 내 게임에 맞게 채워요. 모르는 칸은 0장 "아직 정하지 못한 것"에 적어 두면 돼요.
3. `default.project.json` 맨 위 `"name"`을 내 게임 이름으로 바꿔요.
4. (Rojo를 쓴다면) `01_사용가이드.md` 4장대로 Rojo를 켜고 Studio와 연결해요.
5. AI와 새 대화를 열고 `prompts/01_세션시작.md`를 붙여넣어요.
6. `02_PRD.md` 빌드 순서를 **한 단계씩** 진행하고, 단계마다 `04_테스트체크리스트.md`로 확인한 뒤 `03_진행기록.md`에 적어요.

## 이름에 번호가 없는 파일

`CLAUDE.md`, `README.md`, `default.project.json`, `.gitignore`, `src/` 안의 파일은 **도구가 정확한 이름으로 찾기 때문에** 번호를 붙이지 않았어요. 이름을 바꾸면 AI나 Rojo가 파일을 못 찾아요.
